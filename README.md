# PENGWH

PENGWH 是一个黑白极简、响应式的个人博客，适配手机与桌面屏幕。

- 文章源文件：`content/posts/*.md`
- 当前随包提供：`Claude Opus 5.5：重新定义 AI 编程的边界`
- 构建脚本：`scripts/build.mjs`
- 自动检查：`npm test`
- 管理后台：`/blogcontrol/`（GitHub OAuth 白名单）
- 文章管理：新建、编辑、推送 GitHub commit、删除文章
- 评论管理：后台内嵌 Twikoo 官方管理界面，可在 Twikoo 管理员验证后进行审核；邮箱/IP 是否可见取决于评论服务存储的数据和部署环境
- 生产输出：`dist/`

文章列表数据同时维护在 `public/data/posts.json` 和构建输出 `dist/data/posts.json`。构建时会从 `content/posts/*.md` 读取已发布文章并同步这两份 JSON，避免只更新构建目录而静态源目录仍为空。

项目使用独立的首页、文章列表、分类、标签、关于和文章详情页面。导航在页面顶部采用普通透明排版，向下滚动后变为带背景模糊的悬浮胶囊；手机顶部使用三横线菜单，滚动后胶囊直接显示文字导航。页面包含主题切换、Clawd 首页互动、文章搜索、分类/标签筛选、Twikoo 评论与品牌 404。文章由 Markdown 文件驱动；管理后台中的提交操作会直接创建 GitHub commit，Vercel 构建成功后同步发布。评论信息通过现有 Twikoo 服务管理。

验证命令：`npm test`、`npm run build`。本地检查通过不代表正式域名已部署；需要配置 `ADMIN_SETUP.md` 中的环境变量并重新部署。Twikoo 评论管理还要求 Twikoo 自身的管理员验证，邮箱/IP 等敏感字段不会通过访客评论界面公开。


### 文章滚动显现动画

文章正文支持滚动驱动的逐词显现：文字进入视口下方的触发带后，从轻微模糊、半透明逐渐变为清晰；完成显现的文字会锁定为清晰状态，并随正文自然向上滚动，不会因反向滚动而重播。独立文章页与首页文章阅读层共用此逻辑；系统启用“减少动态效果”时会直接显示全文。
